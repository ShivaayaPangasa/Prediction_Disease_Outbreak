# Multi-Disease Prediction Dashboard

A comprehensive Machine Learning-powered web application that provides early screening for Diabetes, Heart Disease, and Parkinson’s Disease. This project serves as an end-to-end demonstration of the data science lifecycle, from model training to interactive deployment.

## Overview
This application uses pre-trained classification models to analyze user-provided health metrics and predict the likelihood of specific diseases. It is built to facilitate rapid medical data analysis and testing.

## Tech Stack
- **Frontend/UI:** Streamlit
- **Machine Learning:** Scikit-Learn
- **Data Analysis:** Pandas, NumPy
- **Deployment:** Local/Streamlit Cloud

## Features
- **Diabetes Prediction:** Evaluates metrics like Glucose, BMI, and Insulin.
- **Heart Disease Prediction:** Analyzes age, cholesterol, and heart rate data.
- **Parkinson's Prediction:** Uses complex vocal and motor metrics to assess risk.
- **Interactive Interface:** Easy-to-use navigation menu for switching between disease tests.
